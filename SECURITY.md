# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/SMD-Bioinformatics-Lund/smd-reports/security/advisories/new).
Do not include vulnerability details in a public issue.

Include the package version, affected component, reproduction steps and expected impact.
Use example data and remove credentials, patient information and confidential files.

## Dependency alerts

Dependabot alerts are enabled and visible only to users with the required repository
permissions. Automatic security-update pull requests are disabled in GitHub settings;
version-update pull requests are disabled in `.github/dependabot.yml`.

Use private vulnerability reporting for findings and keep discussions in the private
report or draft advisory. Do not copy findings into public issues, pull requests or
workflow logs. Advisories are published only through a deliberate maintainer decision.
Public dependency manifests and third-party advisories remain publicly accessible.
